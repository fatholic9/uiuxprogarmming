## 📖 2. 서비스 소개

**GENSHIN.GG**는 원신 유저를 위한 **종합 캐릭터 공략 및 육성 가이드 플랫폼**입니다.

복잡한 성장 재화 계산과 캐릭터 빌드 설정을 쉽고 빠르게 파악할 수 있도록 최신 메타를 반영한 정보를 제공합니다.

또한 신규 캐릭터와 무기 업데이트 소식을 빠르게 확인할 수 있어, 원신 유저가 캐릭터 육성 방향을 결정하는 데 도움을 줍니다.

## 🚀 3. 주요 기능

### 1. 캐릭터별 맞춤형 육성 가이드

캐릭터의 특성과 역할에 맞춰 효율적인 육성 방법을 제공합니다.

- 추천 무기
- 추천 성유물
- 성유물 주요 옵션
- 특성(스킬) 투자 우선순위
- 캐릭터 돌파 재료
- 육성 재료
- 추천 파티 및 운용 방법

### 2. 신규 캐릭터 및 무기 정보 업데이트

대규모 패치 및 신규 버전 출시 시 추가되는 캐릭터와 무기 정보를 빠르게 제공합니다.

- 신규 캐릭터 상세 정보
- 캐릭터 스킬 및 특성
- 신규 전용 무기 정보
- 무기 스킬 및 옵션
- 최신 버전 업데이트 정보

> 예시 캐릭터: 보댜니차, 베스나 등...
> 예시 무기: 파도의 찬송가, 나비의 우화 등...

### 3. 맞춤형 업데이트 소식 구독

이메일 뉴스레터를 통해 새로운 공략과 업데이트 소식을 편리하게 받아볼 수 있습니다.

- 신규 캐릭터 공략 알림
- 신규 무기 정보 알림
- 버전 업데이트 및 패치 정보
- 최신 게임 정보 뉴스레터

## 🕹️ 4. 이용 방법

### 1단계. 캐릭터 및 무기 탐색

메인 페이지에서 최신 캐릭터 공략과 신규 무기 목록을 확인하고 원하는 캐릭터 또는 무기를 선택합니다.

### 2단계. 상세 공략 및 육성 가이드 확인

선택한 캐릭터의 상세 페이지에서 다음 정보를 확인합니다.

- 추천 빌드
- 추천 무기
- 성유물 세팅
- 특성 투자 순서
- 육성 및 돌파 재료
- 추천 파티
- 캐릭터 운용 팁

### 3단계. 업데이트 소식 구독

페이지 하단의 이메일 입력창을 통해 뉴스레터를 구독하면 새로운 공략과 업데이트 소식을 받아볼 수 있습니다.

## 🧪 5. 사용자 상호작용 및 테스트

### 5-1. 사용자 행동 및 화면 반응

#### 1. 탭 전환 기능

- **사용자 행동:** 탭 버튼을 클릭합니다.
- **확인할 조건:** 클릭한 탭에 대응하는 콘텐츠가 존재하는지 확인합니다.
- **성공 반응:** 선택한 탭이 활성화되고 해당 콘텐츠가 표시됩니다.
- **다른 경로:** 콘텐츠가 없는 탭이 선택되거나 잘못된 탭 요소가 전달되면 존재하지 않는 콘텐츠가 표시되지 않도록 처리합니다.
- **다음 행동:** 다른 탭을 클릭하여 원하는 정보를 탐색합니다.

#### 2. 이메일 뉴스레터 구독

- **사용자 행동:** 이메일 입력창에 이메일 주소를 입력합니다.
- **확인할 조건:** 입력값이 비어 있지 않고 올바른 이메일 형식인지 확인합니다.
- **성공 반응:** 유효한 이메일이면 구독 진행이 가능하다는 안내 메시지를 표시합니다.
- **오류 반응:** 이메일을 입력하지 않았거나 형식이 올바르지 않으면 입력창 아래에 오류 안내를 표시합니다.
- **취소·수정 경로:** 이메일을 수정하거나 입력값을 삭제하면 변경된 값에 맞춰 안내 상태를 갱신합니다.
- **다음 행동:** 이메일 주소를 수정한 뒤 다시 유효성을 확인합니다.

> 실제 이메일 발송 또는 구독 저장 기능이 구현되지 않았다면, 구독 완료가 아니라 입력값 검증 결과를 안내하는 것으로 설명합니다.

#### 3. 이메일 수정 기능

- **사용자 행동:** 이메일 수정 버튼을 클릭합니다.
- **확인할 조건:** 이메일 입력창이 수정 가능한 상태인지 확인합니다.
- **성공 반응:** 이메일 주소를 수정할 수 있도록 입력 상태가 변경됩니다.
- **취소·수정 경로:** 수정 중 다른 주소를 입력하거나 기존 입력값을 유지합니다.
- **다음 행동:** 수정한 이메일의 유효성을 다시 확인합니다.

### 5-2. 기능별 테스트 결과

아래 항목을 실제 브라우저에서 시험하고 결과를 기록합니다.

| 테스트 시나리오         | 예상 결과                       | 실제 결과 |
| ----------------------- | ------------------------------- | --------- |
| 다른 탭 버튼 클릭       | 선택한 탭의 콘텐츠 표시         | 확인 필요 |
| 콘텐츠가 없는 탭 선택   | 잘못된 콘텐츠가 표시되지 않음   | 확인 필요 |
| 올바른 이메일 입력      | 유효한 이메일 안내 표시         | 확인 필요 |
| 이메일 입력 없이 확인   | 필수 입력 안내 표시             | 확인 필요 |
| 잘못된 이메일 형식 입력 | 이메일 형식 오류 안내 표시      | 확인 필요 |
| 이메일 입력값 수정      | 변경된 값에 맞춰 안내 상태 갱신 | 확인 필요 |
| 이메일 수정 버튼 클릭   | 입력값 수정 가능                | 확인 필요 |
| 이메일 입력값 삭제      | 빈 값에 맞는 안내 표시          | 확인 필요 |

**테스트 방법**

1. 정상적인 이메일 주소를 입력해 정상 경로를 확인합니다.
2. 빈 값과 잘못된 이메일 주소를 입력해 오류 경로를 확인합니다.
3. 입력 도중 이메일을 수정하거나 삭제해 상태 변경을 확인합니다.
4. 각 시나리오의 실제 화면 반응을 확인하고 결과를 기록합니다.

### 5-3. 반응형 웹 테스트

| 테스트 화면 |   너비 | 확인 항목                                 | 실제 결과 |
| ----------- | -----: | ----------------------------------------- | --------- |
| 데스크톱    | 1100px | 콘텐츠 및 기능 카드 배치                  | 확인 필요 |
| 태블릿      |  768px | 내비게이션 및 레이아웃 전환               | 확인 필요 |
| 모바일      |  390px | 입력 폼, 버튼, 콘텐츠 잘림 및 가로 스크롤 | 확인 필요 |

**완료 기준**

- 화면 요소가 서로 겹치거나 잘리지 않아야 합니다.
- 모바일에서 불필요한 가로 스크롤이 발생하지 않아야 합니다.
- 탭 전환과 이메일 입력 관련 안내가 정상적으로 작동해야 합니다.
- 정상·오류·수정 경로에서 각 상황에 적합한 안내가 표시되어야 합니다.
